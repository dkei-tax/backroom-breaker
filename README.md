# ムキムキ脱出！バックルーム・ブレイカー

超ムキムキの主人公が、ハンマーでカベをこわしながら全10ステージのバックルームから脱出するアクションゲームです。7歳の子どもと一緒に考えたアイデアから作りました。

## 遊び方

- カギを3つ集めて、出口のドアへ行こう
- ヒビのあるカベはハンマーでこわせる。灰色の鉄のカベはこわせない
- ハンマーボタンを長押しすると「ぐるぐるハンマー」でまわりを全部こわす
- ムキムキボタンで、近くの敵をびっくりさせて止める
- ステージ5と10はボスステージ

## 操作

| | スマホ・タブレット | パソコン |
| --- | --- | --- |
| 移動 | 十字ボタン | 矢印キー |
| ハンマー | ハンマーボタン | スペース |
| ぐるぐるハンマー | ハンマー長押し | X |
| ムキムキポーズ | ムキムキボタン | Z |

## 起動方法

`index.html` をブラウザで開くだけで遊べます。GitHub Pages を有効にすると、URLで公開できます。
